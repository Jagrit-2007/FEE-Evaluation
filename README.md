# Elossence – Fashion Showcase Website

Elossence is a fashion showcase website developed collaboratively using HTML, CSS and JavaScript.

Our goal was to create a platform where users can explore different fashion styles, browse outfit categories and discover fashion inspiration.

## Features
- Separate Men's and Women's sections
- Multiple fashion categories
- Interactive website elements
- Wishlist functionality
- User-friendly interface
